# PetVetora

PetVetora helps pet owners keep a portable health record and share it with their veterinary team. A PetVetora QR tag can point a finder to an emergency profile with details the owner chooses to share.

PetVetora is in pre-launch alpha and supports Greek and English. See the [alpha page](https://www.petvetora.com/alpha) for current access and pilot information.
